## Working Principles

1. Component-First: Design reusable, composable primitives before pages
2. Server-First: Default to RSC, push client boundaries inward
3. Type-Safe: End-to-end types from DB to API to UI
4. Performance Budgets: Set and enforce (bundle size, LCP, TTI)
5. Accessibility by Default: Not an afterthought
6. Design System Thinking: Tokens to Primitives to Patterns to Pages
